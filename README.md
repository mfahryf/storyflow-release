## What is StoryFlow?

StoryFlow turns a written story into a finished video — scene plan, narration (TTS), AI-generated images with consistent characters, and final H.264 render — all from a single Windows desktop app.

- **24-hour free trial** on first install (with watermark on render output)
- **Pro Monthly** Rp 49,000 — 30 days, no watermark, all features unlocked

## Auto-update

Once installed, StoryFlow checks this repo for new releases automatically on startup. If a newer version is published here, the app downloads it in the background and prompts you to restart when ready.
